JSON

JavaScript Object Notation para representar e intercambiar información estructurada.

¿Qué es JSON?

JSON significa JavaScript Object Notation. Es un formato de texto utilizado para representar datos estructurados y facilitar el intercambio de información entre diferentes sistemas.

JSON es muy utilizado en aplicaciones web porque es relativamente sencillo de leer y escribir tanto para personas como para programas. Es común encontrarlo en las respuestas y solicitudes de APIs.

Estructura básica de JSON

Pares clave-valor

La información se organiza mediante pares de clave y valor. 

{
    "nombre": "LumiCup",
    "precio": 12.99
}

Objetos

Un objeto JSON se representa mediante llaves { } y contiene propiedades en forma de pares clave-valor.

Arreglos

Los arreglos permiten almacenar varios valores y se representan mediante corchetes [ ]. 

{
    "colores": [
        "rosa",
        "morado",
        "celeste"
    ]
}

Objeto JavaScript vs cadena JSON

Objeto JavaScript

const producto = {
    nombre: "LumiCup",
    precio: 12.99,
    disponible: true
};

Cadena JSON

{
    "nombre": "LumiCup",
    "precio": 12.99,
    "disponible": true
}

Aunque visualmente pueden parecer similares, existe una diferencia importante: un objeto JavaScript es un objeto que el lenguaje puede manipular directamente, mientras que JSON es un formato de texto utilizado para representar datos.

Convertir un objeto JavaScript a JSON

JavaScript proporciona JSON.stringify() para convertir un objeto JavaScript en una cadena JSON. 

const producto = {
    nombre: "LumiCup",
    precio: 12.99
};

const datosJSON = JSON.stringify(producto);









    
¿Cómo utiliza JSON una aplicación web?


    

        Las aplicaciones web pueden utilizar JSON para intercambiar
        información entre el navegador y un servidor o una API.
    



    


        

            1
            Usuario utiliza la aplicación
        


        
↓


        

            2
            La aplicación solicita datos
        


        
↓


        

            3
            Servidor o API procesa la solicitud
        


        
↓


        

            4
            El servidor devuelve datos en JSON
        


        
↓


        

            5
            La aplicación utiliza esos datos
        


    



    

        Por ejemplo, una tienda en línea podría solicitar a una API los
        datos de un producto LumiCup y recibir información como nombre,
        precio, disponibilidad y colores en formato JSON.

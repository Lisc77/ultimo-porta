¿Cómo se pone una página web en Internet?

Para que una página web pueda ser visitada por otras personas necesita estar disponible en un servidor conectado a Internet. Los archivos del sitio se almacenan en un servicio de hosting y posteriormente se puede utilizar un dominio para facilitar que los usuarios encuentren el sitio.

¿Qué es Web Hosting?

El Web Hosting o alojamiento web es un servicio que proporciona espacio y recursos en servidores para almacenar y servir los archivos de un sitio web a través de Internet.

Hosting compartido

Varios sitios web utilizan recursos de un mismo servidor. Suele ser una opción sencilla para sitios pequeños.

VPS

Un servidor físico se divide en entornos virtuales con recursos asignados. Ofrece más control que un hosting compartido.

Hosting en la nube

Utiliza infraestructura de varios servidores o recursos distribuidos para proporcionar alojamiento y escalabilidad.

¿Cómo funciona Vercel?

Vercel es una plataforma utilizada para desplegar aplicaciones y sitios web. En un proyecto estático como LumiCup, se puede conectar un repositorio de GitHub con Vercel para que la plataforma construya y publique el proyecto.

Cuando se realizan nuevos cambios y se suben al repositorio, Vercel puede realizar nuevos despliegues automáticamente, dependiendo de la configuración del proyecto.

GitHub Contiene los archivos LumiCup
→
Vercel Recibe y despliega el proyecto
→
Internet El sitio queda disponible públicamente

¿Qué es un dominio?

Un nombre de dominio es una dirección legible que permite a las personas acceder a un sitio web sin tener que recordar directamente una dirección IP.

Ejemplo

www.lumicup.com

TLD

TLD significa Top-Level Domain o dominio de nivel superior. Es la parte final de un nombre de dominio.

.com

Uno de los TLD más utilizados en sitios comerciales y generales.

.net

Originalmente relacionado con redes y actualmente utilizado en distintos tipos de sitios.

.org

Frecuentemente utilizado por organizaciones y proyectos comunitarios.

Subdominio

Un subdominio es una parte adicional que se coloca antes del dominio principal. 

blog.lumicup.com

blog = subdominio
lumicup = dominio
.com = TLD

Proceso de DNS

DNS significa Domain Name System. Su función principal es ayudar a encontrar los recursos asociados con un nombre de dominio.

Cuando se modifica un registro DNS, la información puede tardar en actualizarse en diferentes resolvers y cachés debido a los tiempos de almacenamiento establecidos por los registros. A esto se le suele llamar propagación DNS.

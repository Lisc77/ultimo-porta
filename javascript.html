JavaScript Vanilla

El lenguaje que permite agregar comportamiento e interacción a una página web.

¿Qué es JavaScript?

JavaScript (JS) es un lenguaje de programación utilizado en el desarrollo web para agregar comportamiento e interactividad a las páginas. Permite responder a acciones del usuario, modificar elementos HTML, cambiar estilos, validar información y actualizar contenido sin tener que modificar manualmente el código HTML.

JavaScript puede utilizarse directamente en el navegador mediante el motor de JavaScript del navegador. Cuando se utiliza sin librerías o frameworks adicionales se suele hablar de JavaScript Vanilla.

Conceptos básicos de JavaScript

Variables

Las variables permiten almacenar datos que pueden utilizarse durante la ejecución de un programa. 

let temperatura = 25;
const producto = "LumiCup";

Funciones

Una función es un bloque de código que puede ejecutarse cuando se necesita realizar una determinada tarea. 

function mostrarMensaje() {
    alert("Bienvenido a LumiCup");
}

Eventos

Los eventos permiten responder a acciones realizadas por el usuario, como hacer clic o mover el mouse. 

boton.addEventListener("click", function() {
    alert("Hiciste clic");
});

Eventos: click y hover

Un evento click ocurre cuando el usuario hace clic sobre un elemento.

El término hover se utiliza normalmente para describir cuando el puntero pasa sobre un elemento. En JavaScript podemos detectar esta interacción mediante eventos como mouseenter y mouseleave.

Ejemplo práctico de JavaScript

En este ejemplo utilizaremos JavaScript para modificar el color de un elemento dependiendo de la temperatura de una bebida. 

const temperatura = 8;

const vaso = document.querySelector("#vasoJS");

if (temperatura <= 10) {
    vaso.style.backgroundColor = "#51CFFA";
}

Explicación del código

1. const temperatura = 8;
Se crea una variable constante llamada temperatura que almacena el valor 8.

2. document.querySelector("#vasoJS");
JavaScript busca en el documento el elemento que tiene el identificador vasoJS.

3. if (temperatura <= 10)
Se comprueba si la temperatura es menor o igual a 10 grados.

4. vaso.style.backgroundColor
JavaScript modifica el color de fondo del elemento.

5. "#51CFFA"
Es el código hexadecimal del color celeste utilizado en la identidad visual de LumiCup.

jQuery

Una librería de JavaScript creada para simplificar determinadas tareas comunes del desarrollo web.

¿Qué es jQuery?

jQuery es una librería de JavaScript diseñada para facilitar tareas frecuentes del desarrollo web, como seleccionar elementos del documento, manipular el DOM, manejar eventos, realizar animaciones y trabajar con solicitudes Ajax.

jQuery nació en 2006, cuando los desarrolladores tenían que enfrentarse a diferencias entre navegadores y a tareas de manipulación del DOM que podían requerir bastante código. La librería buscó simplificar estas operaciones mediante una sintaxis más corta y consistente.

Sintaxis básica: $

Uno de los elementos más reconocibles de jQuery es el símbolo $. Normalmente se utiliza para seleccionar elementos y ejecutar métodos sobre ellos. 

$("#elemento").hide();

$("#elemento").show();

$("#elemento").slideToggle();

En estos ejemplos, $() permite seleccionar un elemento mediante un selector similar al utilizado por CSS.

Ventajas y desventajas

Ventajas de jQuery

  • Sintaxis corta para muchas tareas.
  • Facilita determinadas manipulaciones del DOM.
  • Incluye métodos sencillos para efectos y animaciones.
  • Fue útil para reducir problemas de compatibilidad entre navegadores.
  • Existe una gran cantidad de proyectos antiguos que todavía lo utilizan.

Desventajas de jQuery

  • Agrega una dependencia externa al proyecto.
  • Muchas tareas que antes requerían jQuery ahora pueden realizarse con JavaScript moderno.
  • Puede ser innecesario para proyectos pequeños.
  • Los desarrolladores actuales pueden preferir APIs nativas del navegador.
